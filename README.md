## Overview of WiCo-MG

WiCo-MG is a Wireless Channel Foundation Model for Multipath Generation designed to generate fine-grained wireless channel multipath parameters directly from RGB sensing images. Built upon the concept of Synesthesia of Machines (SoM), WiCo-MG bridges visual perception and wireless propagation by embedding sensing images and multipath maps into aligned SoM feature spaces. The model adopts a two-stage training framework: the first stage constructs discrete and continuous representations for sensing and channel modalities, while the second stage uses a mixture of shared and routed experts Transformer with frequency-aware routing to map visual features to multipath channel parameters. WiCo-MG enables accurate, scalable, and generalizable multipath generation across different scenarios, carrier frequencies, and UAV flight altitudes, supporting the development of AI-native 6G communication systems.

## Dataset Introduction

The WiCo-MG dataset is a synthetic intelligent sensing-communication dataset constructed for UAV-to-ground communications. It synchronously combines RGB images collected from UAV viewpoints with geometrical channel multipath parameters generated by ray-tracing simulations. The dataset covers diverse urban scenarios, including crossroads and wide-lane roads, multiple carrier frequencies such as 1.5 GHz, 5.9 GHz, 15 GHz, and 28 GHz, and various UAV flight altitudes ranging from low- to high-altitude operations. In total, the dataset contains 23.52k RGB images and approximately 0.13 billion sets of multipath parameters, including power, delay, angle of departure, and angle of arrival. These aligned sensing and communication data provide a foundation for learning cross-modal mappings from visual environments to wireless channel characteristics.

## Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/zengruihan701/WiCo-MG.git
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

It is recommended to use a virtual environment such as `conda`.

### 3. Prepare data and model weights

The dataset and trained model weights will be made publicly available after the paper is formally published.

### 4. Run inference

```bash
python Inference.py
```

This will run the inference pipeline and generate multipath parameter maps.
